# Creche Escola Rei Leão

Site de uma página, feito com HTML, CSS e JavaScript puros. Não precisa instalar nada.

## Como ver

Abra o arquivo `index.html` no navegador. As fontes vêm do Google Fonts, então é preciso estar online para vê-las.

## Como publicar no GitHub Pages

1. Envie esta pasta para um repositório no GitHub.
2. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Espere alguns minutos. O endereço do site aparece na mesma tela.

## Estrutura

- `index.html`: a página inteira, com estilos e scripts no próprio arquivo.
- `img/`: fotos e ilustrações usadas na página.

## O que ainda é exemplo

- Telefone, e-mail, endereço, horários, faixas de idade e perguntas frequentes são fictícios e precisam ser trocados.
- O formulário de contato só monta a mensagem para copiar. Ele não envia nada.
- Os ícones de redes sociais ainda não levam a nenhum perfil.
